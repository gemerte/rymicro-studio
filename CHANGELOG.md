# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.1.0] — 2026-11-16

### Добавлено
- **Пульт для телефона и планшета**: отдельный локальный сервер на `TcpListener` (`0.0.0.0:47832`), токен доступа, мобильная страница с крупными плитками.
- Плитки пульта запускают на ПК Steam, Discord, сайт, проводник, калькулятор, блокнот, скриншот (`Win+Shift+S`), паузу биндов, профили и макросы, а также произвольную команду.
- Управление пультом в настройках: включение, порт, копирование ссылки, «Открыть на ПК», правило брандмауэра, новый код доступа.
- **Быстрые действия** на вкладке «Бинды»: Steam, Discord, сайт, калькулятор, проводник, блокнот, скриншот, вставка текста, команда.
- **Обмен клавиш местами**: `Shift` + перетаскивание и кнопка «⇄ Поменять местами с…» (исправляет односторонний «swap» Win/Alt).
- **Диагностика HID**: `GET /api/lighting-diag` и кнопка «Проверить доступ» — показывает usage page, длины отчётов и вердикт.
- HID-консоль умеет выбирать интерфейс по `usage page` (например, `FF00`) и подстраивает размер отчёта под устройство.

### Изменено
- Инъекция клавиш переведена на scan code (`SendInput` + `KEYEVENTF_SCANCODE`) — модификаторы Win/Alt и игры работают надёжнее.
- В интерфейсе подсветки появился постоянный честный баннер про управление прошивкой.

### Исправлено
- Win и Alt не менялись местами: обмен был односторонним ремапом.
- Калькулятор и другие быстрые шаблоны теперь создаются корректно.

## [1.0.0] — 2026-11-16

### Добавлено
- Глобальный ремап клавиш через низкоуровневый хук Windows (`WH_KEYBOARD_LL`), идентификация по scan code.
- Действия: ремап, комбинация, макрос, текст, запуск программы, команда, мультимедиа, слой, профиль, отключение.
- Слои с режимами удержания и переключения, отдельные наборы биндов на слой.
- Профили с автопереключением по активному процессу.
- Визуальная карта клавиатуры: бейджи действий, живое нажатие, быстрый ремап перетаскиванием.
- Захват клавиши и запись комбинаций/макросов через веб-панель.
- Редактор подсветки боковых панелей: эффекты, цвета, скорость, яркость, зеркалирование, 6 пресетов.
- Экспорт схемы подсветки в PNG и WebM.
- Клиент OpenRGB SDK: проверка устройств, Custom-режим, обновление LED, радуга, выключение.
- Экспериментальная HID-консоль с сохранением пакетов.
- Статистика нажатий по клавишам, топ-12, тепловая карта.
- Трей-иконка с меню, пауза, автозапуск, один экземпляр.
- Локальная веб-панель на `HttpListener` с токеном доступа и SSE-обновлениями.
- Конфиг в JSON с атомарной записью, резервной копией и сбросом к заводским настройкам.
- Сборка одним `build.ps1` без внешних зависимостей.

### Известные ограничения
- Подсветка клавиш управляется прошивкой; программное управление возможно только через OpenRGB или HID-исследование.
- Перехват не работает на экране блокировки Windows и в UAC-запросах.
- Античиты могут реагировать на низкоуровневый хук.
