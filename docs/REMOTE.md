# Пульт для телефона и планшета

Пульт — это лёгкая веб-страница, которую поднимает RYMICRO Studio. Открыли её на телефоне или планшете в той же Wi-Fi сети — и нажимаете крупные плитки, а действие выполняется на компьютере.

## Что умеет

| Плитка | Что делает на ПК |
|---|---|
| Steam | `steam://open/main` |
| Discord | `discord://` |
| Сайт | открывает браузер (по умолчанию — страница проекта) |
| Проводник | `explorer.exe` |
| Калькулятор | `calc.exe` |
| Блокнот | `notepad.exe` |
| Скриншот | `Win+Shift+S` (ножницы) |
| Пауза | включает/выключает бинды клавиатуры |
| Открыть пульт на ПК | показывает эту же страницу на компьютере |

Ниже — переключение профилей, запуск макросов и поле «Своя команда» для `cmd.exe` (например `shutdown /s /t 0`).

## Включение

1. Вкладка **Настройки** → блок **«Пульт для телефона / планшета»**.
2. Убедитесь, что переключатель «Включить пульт» включён. Порт по умолчанию — `47832`.
3. Скопируйте ссылку вида `http://192.168.1.103:47832/?t=…`.
4. Откройте её на телефоне.

Сервер слушает `0.0.0.0`, но это **локальная сеть**, а не интернет: снаружи адрес недоступен, пока вы сами не пробросите порт на роутере. Каждый запрос проверяется по токену из ссылки.

## Если телефон не открывает страницу

1. Телефон и компьютер должны быть в одной сети (не «гостевая» Wi-Fi).
2. Нажмите **«Разрешить в брандмауэре»** — Windows попросит подтверждение администратора и добавит входящее правило для порта пульта.
3. Проверьте, что RYMICRO Studio запущена: в трее должен быть значок **R**.
4. Антивирус со своим файрволом может блокировать порт — добавьте исключение вручную.

## Иконка-приложение на планшете

1. Откройте пульт в браузере планшета.
2. Меню браузера → **«Добавить на главный экран»** (Chrome/Safari/Яндекс).
3. На главном экране появится иконка пульта. Запуск — одним касанием, как обычное приложение.

Это обычная веб-страница, поэтому внутрь не нужно ничего устанавливать и не нужен стор.

## Безопасность

- Токен — случайные 16 hex-символов, хранится в `config/config.json` (`RemoteToken`).
- Кнопка **«Новый код доступа»** меняет токен: старая ссылка перестаёт работать.
- Отключить пульт целиком — переключатель «Включить пульт».
- Пульт не умеет читать файлы и не отдаёт конфиг: только фиксированный список действий, профили, макросы и команда `cmd.exe`, которую вы ввели сами.

## Ограничения

- Пульт работает, только когда компьютер включён и приложение запущено.
- Если компьютер ушёл в сон, плитки не отвечают — разбудите его клавиатурой.
- Заблокированный планшет или телефон сначала нужно разблокировать. Обойти пароль программа не может и не пытается — это защита устройства, а не функция клавиатуры.
