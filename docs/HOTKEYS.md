# Горячие клавиши и жесты

## В панели

| Действие | Как |
|---|---|
| Открыть панель | двойной клик по значку **R** в трее |
| Пауза ремапа | кнопка «⏸ Пауза» в шапке или пункт в трее |
| Сменить профиль | селектор в шапке или подменю «Профиль» в трее |
| Захватить клавишу | кнопка «⌨ Нажать» в инспекторе |
| Записать комбинацию | «⌨ Записать комбинацию» в инспекторе |
| Записать макрос | «● Записать» в инспекторе или в редакторе макросов |
| Отмена захвата | `Esc` |
| Быстрый ремап | перетащить клавишу на другую |
| Обмен клавиш местами | `Shift` + перетаскивание или «⇄ Поменять местами с…» в инспекторе |
| Быстрый шаблон | вкладка «Бинды» → «Steam / Discord / Сайт / …» → выбрать клавишу |
| Тепловая карта | переключатель над клавиатурой |

## Трей-меню

- **Открыть панель** — браузер с токеном.
- **Пауза** — перехват остаётся, но клавиши проходят как есть.
- **Профиль** — список профилей с галочкой у активного.
- **Автозапуск с Windows** — включить/выключить.
- **Выход** — полностью закрыть приложение.

## Системные

| Что | Зачем |
|---|---|
| `config/.port` | хранит `порт|токен` для доступа к панели |
| `logs/app.log` | журнал: запуск, устройство, ошибки хука |
| `HKCU\...\Run\RYMICRO Studio` | запись автозапуска |
| `RYMICRO_Studio_SingleInstance` | мьютекс одного экземпляра |

## Слои: пример «навигация»

1. Вкладка «Клавиатура» → «+ слой» → имя `nav`.
2. На базовом слое выберите `RAlt` → действие «Слой» → имя `nav`, режим «Удержание».
3. Переключитесь на слой `nav` и назначьте:
   - `I` → `↑`, `K` → `↓`, `J` → `←`, `L` → `→`;
   - `U` → `PgUp`, `O` → `PgDn`, `H` → `Home`, `N` → `End`.
4. Сохраните бинд переключателя и включите его.

Теперь `RAlt` работает как Fn: пока он зажат, `IJKL` двигают курсор.

## Профили: пример «Игры»

1. Вкладка «Профили» → «+ Новый профиль» → `Игры`.
2. В поле «Автопереключение по процессу» впишите `cs2` (можно несколько через запятую).
3. Настройте бинды в этом профиле.
4. При запуске игры профиль включится сам; при выходе — вернётся предыдущий.

Автопереключение можно выключить в «Настройках».
