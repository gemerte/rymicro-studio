# Подсветка RY Micro: что реально можно сделать

Клавиатура определяется как **RY Micro USB HID** (`VID 352D`, `PID 2380`, серийник `RYMICRO`). Это бюджетное устройство с RGB-подсветкой клавиш и двумя светящимися полосами по торцам.

## Три уровня управления

| Уровень | Что даёт | Ограничения |
|---|---|---|
| Прошивка (FN) | мгновенная смена режима и цвета, работает без ПК | только встроенные эффекты, нет точных цветов |
| OpenRGB SDK | произвольный цвет и радуга, если устройство поддерживается | нужен OpenRGB и совместимый контроллер |
| HID-консоль | ручная отправка репортов, поиск заводского протокола | экспериментально, можно навредить настройкам |

Программа не перепрошивает клавиатуру и не подменяет драйвер. Всё, что делает панель, — это либо рисует схему, либо просит OpenRGB/HID-устройство применить цвет.

## Схема боковых панелей

Вкладка **Подсветка** позволяет собрать схему для торцов:

- два цвета на каждую сторону, кнопка «⇄ Поменять»;
- эффекты: `Выключено`, `Статичный цвет`, `Градиент`, `Дыхание`, `Радуга`, `Волна`, `Реакция на нажатия`;
- скорость 1–10 и яркость 0–100;
- «Зеркалить левую» — правая панель повторяет левую;
- пресеты `neon`, `cyber`, `sunset`, `ice`, `toxic`, `vapor`.

Результат видно сразу в превью. Кнопка **Скачать PNG** сохраняет статичный кадр, **Записать WebM** — пятисекундную анимацию (запись идёт через `MediaRecorder`, поэтому нужен Chromium-браузер).

Схема хранится в `config/config.json` в разделе `Lighting` и переживает перезапуск.

## OpenRGB

1. Установите [OpenRGB](https://openrgb.org/) и запустите его.
2. Включите SDK-сервер: `Settings → SDK Server → Start Server` (порт по умолчанию `6742`).
3. В панели RYMICRO Studio на вкладке «Подсветка» укажите хост, порт, индекс устройства и количество LED.
4. Нажмите **Проверить** — панель честно скажет, сколько устройств видит SDK.

Если клавиатуры нет в списке OpenRGB, дальше помогут только FN-комбинации или HID-исследование. Это ограничение железа, а не программы.

Команды, которые отправляет панель: `SET_CLIENT_NAME`, `PROTOCOL_VERSION`, `SET_CUSTOM_MODE`, `UPDATE_LEDS`. Цвета передаются в формате RGB по одному байту на канал.

## Диагностика HID

Кнопка **«Проверить доступ»** на вкладке «Подсветка» (или `GET /api/lighting-diag`) перечисляет HID-интерфейсы, которые отдаёт Windows, и показывает для каждого:

- `usage page` и `usage`;
- длину output- и feature-отчёта;
- признак vendor-интерфейса (`usage page ≥ 0xFF00`);
- открывается ли интерфейс на запись.

Что вернула диагностика на этой модели:

```
352D:2380  usage 0x0001 / 0x0006  output 2    — обычная клавиатура
352D:2380  usage 0xFF00 / 0x0000  output 64   — vendor-интерфейс (есть!)
```

То есть у клавиатуры **есть** отдельная vendor-коллекция с 64-байтным output-репортом. Это значит, что подсветку в принципе можно попробовать менять пакетами, но протокол проприетарный: производитель его не документирует, и угадать команды с первого раза нельзя.

Практический смысл: в HID-консоли укажите `usage page = FF00`, тип `output`, и пробуйте короткие пакеты. Всё, что сработает, сохраняйте кнопкой «+ Сохранить». Если подсветка «зависла» — передёрните клавиатуру по USB.

## Что уже выяснено про протокол (версия 1.1.2)

Диагностика `POST /api/hid-caps` читает настоящую структуру отчётов из HID-дескриптора. Для vendor-коллекции она такая:

```
usagePage=0xFF00 usage=0x0000 out=64 in=64 feature=0
  input:  report=4  usagePage=0xFF00  bits=8  count=63  logical=0..255  abs
  output: report=4  usagePage=0xFF00  bits=8  count=63  logical=0..255  abs
```

То есть канал связи — **report ID 4, 63 байта в каждую сторону**, по одному байту на поле. Это не «мёртвый» интерфейс: `POST /api/hid-read` с `reportId: 4` реально получает ответ (`01 00 00 …`), а `POST /api/hid-watch` опрашивает канал и показывает все изменения.

### Почему драйвер тут не поможет

Драйвер — это программа на стороне ПК. Светодиоды стоят на плате клавиатуры и управляются её микроконтроллером: он сам генерирует ШИМ для каждой линии. Сколько бы драйверов ни поставить, цвет появится только если **прошивка клавиатуры принимает такую команду**. Поэтому «переписать драйвер» не добавляет новых цветов — добавлять нужно либо команду в прошивку, либо использовать уже существующий заводской протокол.

### Безопасная проверка за 10 секунд

1. Вкладка «Подсветка» → HID-консоль → **«Слушать канал 10 с»**.
2. Пока идёт опрос, переключите режим подсветки клавишами **FN** (режим, яркость, цвет).
3. Смотрите лог.

- **Пакеты меняются** → прошивка сообщает своё состояние. Тогда в этих байтах находятся режим/яркость/цвет, и их можно менять записью в тот же report 4.
- **Пакет всегда `01 00 00 …`** → канал служебный (обновление прошивки/диагностика). Свои цвета без новой прошивки невозможны.

Если у вас есть заводская программа для этой клавиатуры, самый надёжный путь — записать её обмен через USBPcap и повторить пакеты байт в байт. Это можно сделать в этом же HID-окне.

## HID-консоль

Раздел для энтузиастов. Можно отправить произвольный HEX-пакет как `feature`- или `output`-репорт в устройство `352D:2380`.

- Пакет вводится в виде `05 00 01 FF 00`, разделители любые.
- Report ID — первый байт отчёта.
- Поле `usage page` фильтрует интерфейс: `FF00` — vendor-коллекция, пусто — первый подходящий.
- Размер отчёта берётся из устройства (у vendor-интерфейса это 64 байта).
- Удачные пакеты сохраняются кнопкой «+ Сохранить» и потом отправляются одним кликом.
- **«Прочитать ответ»** (`POST /api/hid-read`) запрашивает один input-репорт и показывает его HEX-дамп. Ничего не меняет в устройстве. Если прошивка не поддерживает чтение, Windows вернёт ошибку 87 — у RY Micro на vendor-интерфейсе `FF00` это ожидаемо.

Что попробовать:
- короткие пакеты вида `XX 00 00 00 00` — многие контроллеры принимают команду в первом байте;
- пакеты с `FF` в качестве яркости;
- если после пакета подсветка «зависла», передёрните клавиатуру по USB.

HID-консоль ничего не гарантирует: у устройства может не быть writable-репортов, и тогда Windows вернёт ошибку. Это нормально и ожидаемо.

## FN-комбинации

Обычно на таких клавиатурах работают:

| Комбинация | Действие |
|---|---|
| `FN + Ins` | смена режима подсветки |
| `FN + Del` | следующий эффект |
| `FN + ↑ / ↓` | яркость |
| `FN + ← / →` | скорость эффекта |
| `FN + 1…5` | цветовые пресеты (зависит от прошивки) |
| `FN + Esc` | сброс подсветки |
| `FN + Win` | блокировка Win |

Точный набор зависит от ревизии платы. Если комбинация не срабатывает — значит, в этой прошивке её нет.

## Что делать, если ничего не помогает

1. Проверьте, что FN-комбинации вообще меняют свет: если да, прошивка жива, вопрос только в программном доступе.
2. Посмотрите в HID-консоли, находится ли устройство и открывается ли оно.
3. Сделайте схему в панели и используйте PNG/WebM как референс — иногда проще подобрать ближайший встроенный режим.
4. Если очень хочется свой цвет на торцах, остается вариант с аппаратной прошивкой (QMK-подобные проекты) — но это уже не про эту программу и с гарантией несовместимо.
